# Partial native/legacy multi_hop_curve_swap recovery

This checkpoint retains 48 recovered handlers and adds a fifth partial path. It does not claim full recovery of `multi_hop_curve_swap` or a deployable replacement.

The accepted branch is one native curve per Pump CPI with fee flag 3, legacy Tokenkeg 82-byte mints and 165-byte token accounts, and an ordinary 166-byte curve. Multi-curve runs, other endpoint-flag combinations, non-native/nested quotes, Token-2022, holder rewards and synthetic completion are explicitly unsupported. Existing complete, Mayhem and tested cashback rejections are retained.

The static mapping traces the captured discriminator through wrapper `0x1295c0`, fixed-account parser `0xdb958`, route handler `0x567d8` and per-curve body `0x5b3b0`. It binds 214 windows reachable through direct internal calls. The handler does not directly reach the stopped instruction bodies, but it shares v3 and transfer-fee helpers; full instruction independence is not established. The bounded implementation adds its own module and entrypoint without changing those shared or stopped implementations.

The fixed account parser enforces the canonical AMM `global_config` PDA and its signer requirement. Every new runtime comparison sends a normally signed test-owned outer transaction to the captured AMM program. That program supplies its own genuine Pump CPI signature. The harness constructs fresh VMs and loads exactly one chosen Pump executable per side. It never synthesizes a PDA signature or bypasses signature verification. Local account state is explicitly synthetic, including the conversion of saved fixture mint/account bytes to legacy layouts.

Within this scope, native buys transfer user lamports before base-token output. Native sells transfer the input tokens before checked reserve/accounting updates. Native buyback uses the observed lamport move, self CPI and SyncNative sequence; the seller payout follows buyback synchronization. The low-input error order, state changes, TradeEvent payload, self-event CPI and 16-byte return are compared with captured execution. This does not establish a general meaning for the unresolved TradeEvent trailing field.

The clean main candidate is 1,534,904 bytes with SHA-256 `6271a6d5782d350f6d716a91712d283592d4589aa8e9befb9c1f1a0dd3ac7ebe`. The main and fully regressed composite are whole-file identical. All 37 differential suites pass: 9,161 existing Pump48 comparisons plus 56 new fixed-scope comparisons. Of those 56, 50 reach Pump, six stop in captured AMM, and only 11 succeed; all 112 outer signatures were independently verified. All 28 unchanged Surfpool runners also pass, covering 1,024 comparisons, 2,048 signed transactions and 2,980 individual signatures.

The frozen [package](../../repro/pump/native-curve-partial-fortyeight/README.md) retains both scratch stages, source/compiler/lock records, the read-only mapping, raw receipts, complete signed transaction bytes, helper/runtime hashes and failed attempts. All 65 final receipt files bind to the tested executable and its actual 36-input composite build. Legacy receipt source maps remain unchanged and are labelled as incidental Pump48 checkout snapshots, not compiled-source provenance. Quote-control directly binds the composite build report and every compiler input. Main receipt reuse additionally requires whole-file main/composite identity.

That diagnostic is retained and excluded from counts; the replacement uses fresh VMs. A separate results-collector schema error occurred after passing runners completed; the raw evidence is retained, and a repeated quote-control run produced identical JSON. Neither repeated execution adds unique cases.

The known `sell_v2` quote-transfer-fee minimum-output/event mismatch is unchanged. Stopped v3 extension/fee, incentives and initializer recovery lanes remain excluded. Existing approved regression fixtures were replayed without expansion. Full original-byte equality, historical source/compiler/dependency identity, exhaustive account and token-extension behavior, and the security audit remain incomplete.
